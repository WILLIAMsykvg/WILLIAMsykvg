## ProofPay

A shopping agent for real Hong Kong Shopify stores. It compares prices and fills the cart, but it has no payment tool and never sees your location, purchase history or card. Before money moves, location, bank and merchant each sign one yes/no answer. The phone scores them. The bank recomputes. Those answers can only make a payment stricter.

- Live demo: https://hacku-local-deployment.onrender.com
- Code: [HACKU-local](https://github.com/WILLIAMsykvg/HACKU-local)
